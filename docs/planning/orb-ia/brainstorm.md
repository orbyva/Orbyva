- A ideia é sempre o Orb interagir com o usuário, para que os dados sejam cadastrados de forma correta e para que ela sugira coisas sobre os dados daquele usuário

- O usuário pode perguntar sobre os dados dele sobre todos os módulos. Ex.:
    - Tenho algum orçamento estourado? Quanto já gastei com fast-food?
    - Me diga um filme de comédia aleatório que ainda não assisti que está na minha lista.
    - Eu posso parcelar essa compra de valor x?
    - Quantas parcelas faltam para eu quitar o meu celular?
    - Quanto falta para eu bater a meta de ler 1000 páginas de livro no ano?
    - Quais os gastos que posso diminuir para que eu tenha um saldo 10% maior que o desse mês no mês seguinte?
    - O que irei fazer amanhã em São Paulo?
    - Quanto eu ficarei de saldo se eu parcelar uma compra em 12 vezes no valor de R$5000?

- O usuário pode pedir para o Orb criar novos dados em todos os módulos.Exs.:
	- Categorias:
		- Cria categoria Alimentação com as subcategorias, fast-food, lanche e padaria.
		- Cria a subcategoria Uber dentro da categoria Transporte.
            - Se o usuário não falar qual categoria, o Orb vai dizer algo tipo, "isso parece se encaixar dentro da categoria: Transporte, posso inserir essa subcategoria dentro de Transporte?"

    - Orçamento:
        - Defina o orçamento de fast-food desse mês para R$ 800.
            Aí o Orb vai falar "Deseja que esse orçamento seja refletido para os meses sequentes ou só para esse mês?"
        - Exclua o orçamento de lazer desse mês
        - Replique o orçamento do mês de julho para todos os meses desse ano
            Aí o Orb fala: "Até quando?"
